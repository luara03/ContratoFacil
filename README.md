# ContratoFacil - App móvel de finanças

Aplicativo mobile (React Native + Expo) para gerenciar finanças **pessoais** e **profissionais** em uma única interface.

## Funcionalidades
- Visão de saldo total, receitas, despesas e saldo por área.
- Cadastro rápido de lançamentos (descrição, valor, área e tipo).
- Lista de últimos lançamentos.

## Como executar
```bash
npm install
npm run start
```

Depois, use o app Expo Go no celular para abrir o QR Code.

## Scripts
- `npm run start` inicia o Expo
- `npm run android` abre no Android
- `npm run ios` abre no iOS
- `npm run web` abre no navegador
- `npm run typecheck` valida TypeScript
