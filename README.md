# ContratoFacil

Aplicativo web simples para criar anúncios de achadinhos a partir de um link.

## Funcionalidades

- Gera anúncio automaticamente com:
  - imagem do produto;
  - copy pronta para divulgação;
  - CTA sugerida;
  - link clicável para a oferta.
- Permite editar copy e CTA antes de publicar.
- Botão para copiar a copy.

## Como executar

```bash
python3 -m http.server 8000
```

Abra: `http://localhost:8000`
